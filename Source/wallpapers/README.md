# wallpapers

Wallpaper images shipped with HyKr. See [`../CREDITS.md`](../CREDITS.md)
for source attribution.

- Loose files in this folder are from [elifouts/Dotfiles](https://github.com/elifouts/Dotfiles).
- Each subfolder (`nord/`, `anime/`, `m-26.jp/`, `apocalypse/`, `outrun/`,
  `evangelion/`, `stalenhag/`, `pixel/`, `radium/`) is a themed pack
  pulled wholesale from [dharmx/walls](https://github.com/dharmx/walls).

`anime/` also holds a few images added by hand rather than from that pack
(the five 2000px-wide ones added in November 2026 — the hangar, the snowy
mountain, the white city stairs, the sunlit clearing and the overpass at
dusk). They're JPEGs on purpose: `hypr/wallpaper.sh` and the Quickshell
wallpaper picker only list `.jpg`/`.jpeg`/`.png`, so `.webp` originals were
converted.
